# EverAfter — Wedding Planner Website

A responsive wedding planning website made with HTML, CSS, and vanilla JavaScript.

## Project files
- `index.html` — website sections and content
- `style.css` — responsive styling, layout, and design system
- `script.js` — mobile navigation, current year, and contact form demo interaction

## Open in VS Code (Windows)
1. Extract the ZIP.
2. Open VS Code.
3. Select **File → Open Folder** and choose `wedding-planner-website`.
4. Open `index.html`.
5. For easiest preview, install the **Live Server** extension, right-click `index.html`, then select **Open with Live Server**.

## PowerShell quick start
After extracting the project, open PowerShell in the project folder and run:
```powershell
code .
```
If VS Code's `code` command is not enabled, open VS Code manually and use **File → Open Folder**.

To open the page in your default browser without Live Server:
```powershell
Start-Process .\index.html
```

## Publish with GitHub Pages
1. Create a GitHub repository named `wedding-planner-website`.
2. Upload the project files (`index.html`, `style.css`, `script.js`, `README.md`) to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for the deployment and copy the published URL.

## Before using as a real business website
- Replace the fictional brand name EverAfter with your business name.
- Replace sample photos with your own licensed photography.
- Add your real phone, email, social links, and location.
- The contact form currently demonstrates front-end validation and confirmation only. Connect Formspree, Netlify Forms, or a backend to receive inquiries.
- Update testimonial text to real client feedback before public launch.

Images currently load from Unsplash over the internet; an internet connection is needed for those photos.
